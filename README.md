Find Movies App

A sleek, real-time movie discovery app using the TMDB API. Search for trending content, track your search history, and filter dynamically — all while Appwrite handles backend data and persistence.
Features

    Real-time trending movies from TMDB

    Smart state management for a smooth UX

    Appwrite backend for user data and search tracking

    Loading animations on fetch and page load

    Dynamic search & filter interactions
